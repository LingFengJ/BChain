# BChain
Bchain is a P2P Blockchain simulator in Java, in a multithread environment \newline We simulated the Bitcoin system and implemented consensus algorithm, block validation, chain synchronization, proof of work mechanism and analyzed the security of the system. <br>
[A short documentation of our project](https://github.com/user-attachments/files/17787664/Programming_2_project.pdf)
<br>

## Quick Start 
```bash
git clone https://github.com/LeothDev/BChain
cd Bchain
```
To start the simulation, compile and execute TestBlockChain.java:
```
javac TestBlockChain.java
java TestBlockChain
```
